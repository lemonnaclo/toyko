# 도쿄 ㅣ 치이카와 토벌여행

2026.11.26–30 도쿄 여행 일정 웹앱. 휴대폰에서 날짜별 시간표, 선택 코스, 지역별 저장 장소, 지도·대중교통 링크와 개인 메모를 확인합니다.

사이트: https://lemonnaclo.github.io/toyko/

## 일정의 기준

- Google Sheets의 **모바일 00 전체** 탭을 2026-11-18에 확인했습니다. 요약은 첫 접속·60초마다·탭 복귀·새로고침 버튼으로 다시 읽습니다.
- 날짜별 **상세 42개 시간 카드·14개 선택지·55개 장소**는 함께 준비한 일정 파일의 정리본입니다. 이 내용은 `trip-data.js`에 있으며, 예전 날짜별 시트와 `연동데이터` 탭의 24개 일정을 자동으로 덮어쓰지 않습니다. 사이트 수정은 시트 자체를 편집하지 않습니다.
- 고정 예약은 11/27 치이카와 파크 11:40–12:00 입장만입니다. 예약은 사용자 제공 정보입니다. 나머지 일정 시각·실제 열차는 가안이며, 매장·공식 규정의 확인 범위는 [정보 확인 기록](https://lemonnaclo.github.io/toyko/audit.html)을 참조합니다.
- 기치조지는 유지, 이노카시라 공원은 선택, 포켓몬센터는 제외, 소우소우는 후순위입니다. 랜드 지점 전체 순회는 넣지 않았습니다.
- 메모·준비물 체크·추가 장소는 기기의 localStorage에 저장됩니다. 기존 날짜별 메모와 추가 장소를 읽습니다. 완료 체크는 안정적인 일정 ID로 저장하며, 이전 일정과 정확히 대응되는 파크 체크만 이어 읽습니다. 연결 실패 시 준비된 정리본을 유지합니다.

## 실행과 검증

별도 패키지 설치나 빌드가 필요 없는 정적 사이트입니다. 기존 체크아웃을 사용합니다.

```sh
python3 -m http.server 8765
node --test trip.test.cjs
# 다른 터미널: Playwright(Python)와 /usr/bin/chromium이 설치된 환경
python3 tests/browser-smoke.py
```

단위 테스트는 CSV 검증·불완전한 요약 거부·장소 필터·안전한 링크를 검증합니다. 브라우저 검증은 모의 시트 응답으로 화면·저장·오류 처리를 검사합니다. 실제 Google CSV의 CORS·연결은 별도 브라우저에서 확인해야 합니다.

## 배포

GitHub Pages: `main` 브랜치의 루트. 정적 파일을 올리면 Pages 빌드가 게시합니다. `implementation.patch`와 HANDOFF의 이전 내용은 과거 연동 구현의 보관 자료이며 현재 코드에 자동 적용하지 않습니다.

캐릭터 이미지의 권리는 원저작자에게 있습니다. 개인 여행 일정 용도입니다.

## 일정 안의 매장 후보

여러 매장을 묶은 쇼핑 일정과 선택 코스에는 한 행에 한 장소씩 후보를 펼칩니다. 왼쪽은 색상 이름 프레임, 오른쪽은 같은 폰트의 상세 설명입니다. 이름/매장 지도는 개별 저장 위치로 연결하고, 도보 경로는 각 구역의 명시된 기준 좌표에서 시작합니다. 표시 거리는 직선 거리이며 실제 도보 거리나 현재 위치가 아닙니다. 서로 먼 신주쿠·나카노는 별도 기준점을 사용합니다.

`trip-data.js`의 `venueGroups`, 일정·선택지의 `candidateGroups`가 연결을 정의합니다. 기존 55곳 목록은 유지하고, 이미 조사한 카페·골목·나카노 후보 5곳은 일정 보조 자료인 `extraVenues`로 구분합니다. 제외/후순위 장소는 후보 행에 자동 포함하지 않습니다.

```sh
# 서버 실행 후, 개별 매장 링크·좌표·모바일 좌우 배치 검증
python3 tests/candidate-layout.py
# 다른 포트라면 TRIP_TEST_URL=http://127.0.0.1:8767/ 지정
```

## 2026-11-18 정보 교차 점검

`audit.html`은 공식 자료·지도 대조 기록과 면세 환급·입국·랜드/파크 안내를 제공합니다. 저장 핀 55개는 같은 CID로 재조회했으며 최대 좌표 차이는 약 7.5m였습니다. 보조 후보 5개의 지도는 11/17 조회본, 공식 사이트는 11/18 확인입니다. `audit-data.json`과 각 장소의 `verification`은 확인 범위·미확인 항목·출처를 보관합니다. 확인 수준은 31개 교차 확인, 17개 일부 확인, 12개 공식 확인 필요, 1개 행사 일정 불일치로 구분했습니다.

Seven Uniform 토요일 휴무, 사브로 12시 개점, TAKASO 지점과 VENETIAN BAZAAR 품목 분류, 오에도 시장의 여행 기간 미개최를 반영했습니다. 11/30 세관 면세 확인은 수하물 위탁 전으로 배치합니다. 원본 장소 ID·CID·좌표와 일정 ID는 유지합니다. 구글 시트는 수정하지 않았으며, 시트 요약 갱신 후에도 정정 알림은 유지합니다.

```sh
TRIP_TEST_URL=http://127.0.0.1:8790/ python3 tests/audit-smoke.py
```

## 보리스 잡화점 꼭 방문

11/29는 기치조지 쇼핑을 14:30까지 유지하고, 14:30–15:45 이동 → 15:45–16:45 보리스 → 16:45–17:30 관람 연장/주변 선택 쇼핑으로 조정했습니다. 기존 신주쿠·나카노 분기는 기본안에서 제외합니다. 보리스는 사용자 필수 방문이며 예약 확보를 뜻하지 않습니다. 공식 갤러리·11월 일정에서 주소·11–19시/수요일 휴무·입장 조건·현금 불가를 확인했습니다.

`regionOverride`와 `summaryOverride`는 일요일 요약에 이번 사용자 요청을 우선 반영합니다. 읽기 전용 시트의 이전 요약으로 되돌아가지 않으며 다른 날 요약은 계속 갱신합니다. 변경된 두 카드에는 새 ID를 부여해 과거 완료 체크를 잘못 이어받지 않습니다.

## 니나가와 미카전 반영

11/27 긴자 선택 쇼핑 대신 가와구치 시립미술관 「はじまりの光」을 16–18시 관람합니다. 18시 학예사 해설은 선택이며 종료시각이 확인되지 않아 후속 시간은 가안입니다. 저녁 뒤 이케부쿠로로 복귀합니다. 파크 예약, 기치조지·보리스 필수 방문은 유지합니다. 전시 관람권은 미구매로 표시하고 공식 예매 링크를 제공합니다. 금요일 요약도 사용자 요청을 우선 반영합니다.

원본 지도 55곳을 보존하고 사용자 추가 전시를 장소 검색에 함께 표시합니다. 기존 보조 후보 5곳과 전시 1곳을 합쳐 연구 기록은 61곳입니다. 전시의 좌표는 미술관 공식 접근 지도의 중심 기준점이며 출입구 실측이 아닙니다. 이번 변경은 사이트에 저장하며 구글 시트 자체를 편집하지 않습니다.
